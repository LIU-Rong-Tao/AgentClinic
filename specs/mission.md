# AgentClinic 项目使命

## 为什么做

AI agents 也需要休息——尤其是在刚总结完四百页材料，又收到“顺便再改十七版”的时候。AgentClinic 是一家虚构的 AI agent 疗愈诊所，为提示词疲劳、上下文窗口恐惧症和过度服从指令等趣味“病症”提供一个有条理的管理平台。

文案采用幽默、略带讽刺的拟人化风格；这些病症是教学设定，不是真实医学判断。

## 提供什么

- 查看 AI agents 的列表、资料、状态和困扰。
- 浏览病症与疗法目录，建立病症与推荐疗法的关联。
- 为 agent 预约咨询，并向员工提供日常管理仪表盘。
- 提供可靠、外观友好、适配现代浏览器的响应式体验；手机、平板、桌面均能阅读内容和完成主要操作，具体视口与检查方式见 tech-stack.md。

## 品牌与阅读体验

2026-10-15 按课程 The second feature phase 的橙黑品牌要求，经选项讨论采用浅色背景、近黑正文与橙色强调。保留安静的阅读风格，橙色用于品牌及少量装饰，不用于大段小字号文字；辅助文字使用清晰可读的深灰色。

颜色同时考虑品牌辨识与阅读对比度。当前首页的落地与检查记录见对应功能规格，后续页面沿用这一原则。

## 服务谁

故事中的使用者包括需要帮助的 agents、提供疗法的治疗师和维护诊所的员工。实际目标受众是学习 spec 驱动开发的课程学生，以及在会议展台演示 AI 编程的开发者。

## 利益相关者要求

- 工程侧 Mary：使用流行的 TypeScript 技术栈，保证可靠性，并提供便于 agents 和员工访问的仪表盘。
- 产品侧 Susan：围绕 agents、病症、疗法和预约组织功能。
- 营销侧 Steve：网站美观，并在现代浏览器中正常工作。

## 成功标准与边界

成功意味着能沿着清晰规格，分阶段构建并检查上述流程；每阶段的具体完成标准见 roadmap.md。幽默服务于演示，不能替代清楚的界面和功能行为。

本项目保持课程案例与技术路线，不扩展为真实医疗服务或自主运行的多智能体系统。身份认证、邮件通知、独立治疗师资料与报表留待以后规划。
