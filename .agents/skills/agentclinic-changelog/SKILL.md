# AgentClinic 变更日志

仅用于当前 AgentClinic 仓库。显式调用后执行，不自动在每次修改时运行。

1. 确认仓库根目录、当前分支与工作区状态，阅读已有 CHANGELOG.md。用有界的 git log、git show 和 git diff 核对实际变更；未跟踪文件也要检查，不能只看提交标题。
2. 首次创建时从 Git 历史归纳有意义的功能、修复和开发流程变化，按 Asia/Shanghai 日期分组，日期标题使用 YYYY-MM-DD，最新日期在前。没有可靠日期或依据时明确说明，不猜测。
3. 合并前更新时，检查自上次已记录状态以来的提交及待合并改动，同日合并条目并去重。只计划、未实现或未验证的事项不能写成已经完成；可以准确记录“更新规划”，但不能写成“已交付对应功能”。不宣称尚未发生的合并或发布。
4. 保留已有有效条目，用简短中文描述用户可见变化及重要开发流程变化，不逐条罗列格式化、锁文件噪声、空初始化提交或敏感信息。重复执行且代码无变化时不制造重复条目。
5. 写入根目录 CHANGELOG.md，核对每项有证据，报告新增或调整内容以及未覆盖事项。技能本身不提交、合并、删除分支或推送；这些动作仅依据单独的用户授权执行。
